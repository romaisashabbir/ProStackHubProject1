# AlgoViz — Algorithm Visualization Engine

AlgoViz is an interactive algorithm visualization project developed as part of the **ProStackHub Python Programming Internship**.

The project helps users understand how shortest-path algorithms work by allowing them to create a custom weighted graph and visualize the execution of **Dijkstra's Shortest Path Algorithm** step by step.

---

## 🚀 Features

- Interactive graph creation
- Add custom nodes
- Add weighted edges
- Select start and destination nodes
- Dijkstra's shortest-path algorithm
- Step-by-step algorithm execution
- Play, pause, next, and back controls
- Visual representation of visited and current nodes
- Shortest path and total distance display
- Actual algorithm step count
- Time and space complexity information
- Responsive dark-themed interface
